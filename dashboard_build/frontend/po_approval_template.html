A PO is "In approval" when its processing state in the SAP view is 03, or when it is on the approver list (see below). This matches the SAP app Manage Purchase Orders with Status = In Approval (checked for September 2026: 3 POs). POs in state 08 are Rejected in SAP (checked against an export of the SAP Purchase Order Items list: all 5 rejected items are state 08), so they are kept apart ("Show" filter). The oldest PO is shown first, and the age counts calendar days from the PO creation date. Click the item count of a PO to see its items. Values are the net order value in INR; a PO in another currency shows its own currency and is not added into the INR totals. The approver is not in any SAP view the dashboard can read, so it comes from a list exported from the Manage Purchase Orders app (Status = In Approval, then Export to Excel) and saved as po_approvers.xlsx in the dashboard_build/backend/data folder; it is read again on every refresh. A PO that was changed after its release is In Approval in SAP while the data view still shows it as released (state 05); such a PO is only found through the approver list and is marked with * next to the approver. The dashboard cannot see when it is approved, so such a PO stays listed until it is removed from the list or the list is exported again. Likely approver (shown as ~ name in italics): the approver is decided by SAP's workflow, which the dashboard cannot read. The likely approver comes from po_approver_rules.csv: the approver list sent on 18-Oct-2026 (how many POs each approver has pending) was matched with the purchasing group, PO type and value of the POs in approval, and the POs SAP showed with a known approver. It reproduces those counts, but it is an inference, not a confirmed approver; the hover on ~ name gives the basis and how strong it is. The PO creation date starts as the whole current month and moves to the next month by itself; change it (or clear it with the x on its chip) to see older POs. Data is refreshed from SAP at most every 30 minutes, or with the Refresh button.
